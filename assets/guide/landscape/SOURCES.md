# Landscape artwork

These independent transparent landscape layers are adapted from **Glitch**, by **Tiny Speck**.

- Source collection: https://opengameart.org/content/glitch-groddle-assets-png
- Source PNG: https://opengameart.org/sites/default/files/tree_plane_01a_g1.png
- Source archive for the other layers: https://opengameart.org/sites/default/files/groddle_png.zip
- Published license: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Retrieved: 2026-10-25
- Local modifications: foliage and bark color grading to the site's blue-green palette; WebP encoding while retaining transparency. The original brushwork and silhouette are preserved.

| Local file | Original file in `groddle_png/` |
| --- | --- |
| `tree.webp` | `tree_plane_01a_g1.png` |
| `tree-round.webp` | `tree_deciduous2.png` |
| `shrub.webp` | `bush_seethrough_01b_g1.png` |
| `daisies.webp` | `flower_bush_7.png` |
| `cloud.webp` | `cloud_fluffy_2.png` |

The cloud keeps its original colors. Other layers were color graded offline, preserving their alpha channels. The layers use different parallax speeds and slight wind movement at runtime.

The original collection credits Tiny Speck, with PNG conversion submitted by TheValar. CC0 permits reuse, modification and redistribution without an attribution condition. This site nevertheless credits the source in its artwork notes.

The sky, water, path, movement, shadows and research landmarks are original site code. Landscape assets are separate layers; no captured website text or screenshot is used as a background.
